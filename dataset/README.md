\# Dataset



This project uses road-surface images for pothole detection using YOLOv4.



The dataset contains:



\- Road images without visible potholes

\- Images containing potholes

\- YOLO object-detection annotations for pothole localisation



The complete dataset is not included in this repository because of its size.



For the dataset structure and preparation process, refer to:



\[`MSc\_Final\_Project.ipynb`](../notebooks/MSc\_Final\_Project.ipynb)
